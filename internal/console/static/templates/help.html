Getting Started with OXI Metric

Integrate OXI Metric into your app in minutes. Choose your platform below, create a project token in the Projects page, and start tracking events.

Server URL: {{.Domain}}
This is your OXI Metric server endpoint. Use it in the SDK initialization below.
1. Install the SDK
# pubspec.yaml
dependencies:
  oximetric:
    git:
      url: https://github.com/oxisoft/oximetric-flutter-sdk.git
2. Initialize
import 'package:oximetric/oximetric.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  await OxiMetric.initialize(
    serverUrl: '{{.Domain}}',
    token: '<your-project-token>',
  );

  runApp(MyApp());
}
3. Track Events
// Track an event with typed properties
OxiMetric.track('purchase', properties: {
  'amount': 29.99,
  'currency': 'USD',
  'is_first_purchase': true,
  'item_count': 3,
});

// Track a simple event
OxiMetric.track('page_view');
4. Identify Users (Optional)
// After user logs in — SDK hashes the identifier automatically
OxiMetric.identify('user@example.com');

// Opt out of tracking (e.g., user declines analytics)
OxiMetric.optOut();

// Opt back in
OxiMetric.optIn();
1. Add Dependency
// build.gradle.kts
dependencies {
    implementation("io.oxisoft:oximetric-android:1.0.0")
}
2. Initialize
import io.oxisoft.oximetric.OxiMetric

class MyApplication : Application() {
    override fun onCreate() {
        super.onCreate()

        OxiMetric.initialize(
            context = applicationContext,
            serverUrl = "{{.Domain}}",
            token = "<your-project-token>"
        )
    }
}
3. Track Events
OxiMetric.track("purchase", mapOf(
    "amount" to 29.99,
    "currency" to "USD",
    "is_first_purchase" to true,
    "item_count" to 3
))

OxiMetric.track("page_view")
4. Identify Users (Optional)
OxiMetric.identify("user@example.com")

// Opt out / opt in
OxiMetric.optOut()
OxiMetric.optIn()

API Reference

All SDKs communicate with the following REST endpoints:

MethodEndpointDescription
POST/api/v1/deviceRegister or update device info
POST/api/v1/trackSend batch of events with properties
POST/api/v1/identifyLink device to anonymous user

All requests require the X-Token header with your project token.
